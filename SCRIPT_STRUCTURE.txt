║                   CUSTOMIZATION POINTS                             ║
╚════════════════════════════════════════════════════════════════════╝

Easy Modifications (Configuration Constants):
  → Jump Height:      Change BOUNCE_FORCE (50-100)
  → Cooldown Time:    Change COOLDOWN_TIME (0.5-1.5)
  → Animation Speed:  Change BOUNCE_DURATION (0.2-0.5)
  → Compression:      Change SCALE_FACTOR (0.7-0.95)
  → Side Filter:      Change VELOCITY_THRESHOLD (3-10)

Medium Modifications (Function Bodies):
  → Jump Direction:   Modify Vector3 in applyBounceForce()
  → Visual Effect:    Customize Tween in playBounceEffect()
  → Conditions:       Add checks in onTouched()

Advanced Modifications:
  → Particle Effects: Add to playBounceEffect()
  → VIP Systems:      Add rank checks in onTouched()
  → Directional:      Calculate velocity based on trampoline.CFrame
  → Network Events:   Add RemoteEvent for client feedback
